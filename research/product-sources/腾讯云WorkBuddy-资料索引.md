## 资料缺口

1. **生态规模口径**：开放平台首页宣称“10 万+生态资产、3000 万+累计安装”，但未公开统计口径、去重方式和时间范围，报告仅按厂商口径记录。
2. **能力分类口径**：首页把五类能力列为 Buddy 应用、专家、Skill、连接器和硬件；发布报道列出的五项包含专家团和外部应用。报告按公开文档的完整对象体系说明，不把任一枚举视为唯一分类。
3. **Token 有效期**：第三方应用页称 `access_token` 有效期 24 小时，Open API 示例返回 `expires_in: 3600`（1 小时）。接入方应以接口实际返回值为准并等待官方澄清。
4. **商业规则**：未发现面向伙伴的公开上架费用、收入分成、结算周期、流量分配机制或服务等级承诺。
5. **API 运营**：文档已经列出较完整 API，但未发现公开版本稳定性承诺、调用配额、限流策略和 API 价格。
6. **硬件治理**：当前硬件接入文档与第三方应用文档存在共用流程的迹象，但针对设备生命周期、固件、安全认证和离线策略的细节仍有限。
7. **产品边界**：WMA/Enterprise 已公开较完整的 Runtime 与 AgentOps 能力，但开放平台开发者是否可直接获得全部能力、对应套餐和 API 权限尚未说明，不能把两个入口的能力简单等同。

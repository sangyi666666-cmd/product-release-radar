## Top 5

### 1. GPT-6 Astra 将长任务 Agent 的工具、上下文、控制与安全能力收敛为一个旗舰模型｜95 分

**可验证事实**：OpenAI 官方 API 文档将 `gpt-6-astra` 标为默认旗舰模型，用于复杂推理、编码、Computer Use、研究和文档创建；其上下文窗口为 1,050,000 Token、最大输出为 128,000 Token，文本价格为每百万输入 Token 10 美元、输出 Token 50 美元。该模型支持 `low` 至 `max` 的推理强度，以及 Web Search、File Search、Code Interpreter、Hosted Shell、Apply Patch、Skills、Computer Use、MCP 与 Tool Search 等工具。官方模型指南还列出异步工具调用、中途指令调整、不中断缓存地调整推理强度和失配监控等新能力。[GPT-6 Astra 模型页](https://developers.openai.com/api/docs/models/gpt-6-astra) · [GPT-6 Astra 模型指南](https://developers.openai.com/api/docs/guides/latest-model)

**产品判断**：这不是单项 Benchmark 或单一编程模型升级。它同时改变了 Builder 的工具接口、Runtime 的异步等待和中途控制、Context 的长任务承载、Computer Use 的执行入口、模型成本与缓存策略，以及企业的安全监控边界，因此应作为 Agent Infra 顶级信号处理。

**启示**：企业 Agent 的模型适配层需要从“模型名 + Prompt”升级为版本化运行合同，至少记录 `模型快照、上下文预算、推理强度、工具集合、异步调用策略、人工中途干预、缓存、成本上限、安全告警和回退模型`。模型上线、限量开放与全量 GA 需要分别登记。

**建议动作**：选择一个含浏览器、文件、Shell 与长上下文的真实任务，用同一评测集对 Astra 与现有默认模型比较：任务完成率、工具失败恢复、人工中途改需求、总 Token/成本、等待时长和安全拦截。访问范围未确认前，只在可控试用环境中验证。

### 2. Hermes Agent 持续进入 GitHub Trending，但没有窗口内正式版本｜42 分（弱信号）

**可验证事实**：9 月 7 日的 GitHub Trending 页面出现 `NousResearch/hermes-agent`。该项目公开 Release 页显示最新正式版本为 `v2026.8.31`（Hermes Agent v0.21.0），并非本窗口发布。[GitHub Trending](https://github.com/trending?since=daily) · [Hermes Agent Releases](https://github.com/NousResearch/hermes-agent/releases)

**产品判断**：开源社区对可自托管、工具驱动、具备持久记忆的 Agent Harness 仍有兴趣，但当前仅能证明关注度；不能推导为版本成熟、企业可用或正在替代托管 Runtime。

**启示**：开源项目进入竞品池前，至少补齐版本节奏、维护者响应、工具/权限边界、恢复能力、评测、许可证和企业部署责任等证据，避免用 Star 或 Trending 排名替代产品验证。

**建议动作**：把 Hermes Agent 放入下周开源 Watchlist；只有出现正式 Release、关键安全/运行时变更，或有可核验企业采用时，再做对比试用。

## 基础模型与 Agent Infra

**GPT-6 Astra（补录，P0，高）**覆盖 Agent Infra 的多个维度：

- **Builder / Tool**：支持 Function Calling、Structured Outputs，并在 Responses API 中支持 Web/File Search、代码执行、Shell、MCP、Skills 和 Computer Use；
- **Runtime / Context**：105 万上下文、异步工具调用、中途指令调整和推理强度动态调整，针对的是可持续多步执行而非单轮回复；
- **Evaluation / Governance**：官方披露失配监控，并要求将工具调用迁移到 Responses API；模型行为、工具权限和安全告警需要进入同一评测与审计链；
- **成本与入口**：长上下文有阶梯价格，Batch/Flex 与 Fast 模式也有不同成本和限制；模型已在 API 文档中作为默认旗舰模型呈现，但实际访问范围仍应按组织、套餐和区域确认。

OpenAI 的能力表述属于厂商一手资料，尚不能替代企业场景的完成率、成本和安全实测。Claude Fable 5.1 与此前国内模型版本仍按既有访问范围处理；发布、滚动开放、定向访问与普遍可用不可混写。
